# libcst, pinned and hash-checked — the Python 4a/4b codemod engine (phase 5, G2).
#
# ⛔ FETCHED AT INSTALL, NEVER VENDORED. libcst ships a compiled native extension, so a vendored
# copy would have to carry one wheel per (platform, Python minor). It is installed instead with
# --require-hashes, which is what makes "fetched at install" safe: pip refuses anything whose
# sha256 is not listed below, so a compromised or swapped wheel fails the install rather than
# running.
#
# ⚠️ --no-deps is deliberate: the codemod path never imports libcst's optional yaml dependency
# (measured, prototype § 2), and pulling it in would need its hashes here too.
#
# 15 wheels = cp310–cp314 × {macosx_11_0_arm64, manylinux_2_28_x86_64, manylinux_2_28_aarch64}.
# A cell with no wheel (Intel macOS, Windows) fails the import test, and the codemod then reports
# `libcst_unavailable` — a decline that is stated, never a guess.
#
# ⚠️ `import libcst` IS the test, not the pip exit code: the failure the prototype actually
# measured was `cannot import name 'native'` from a zipimport, which installs cleanly.
#
# To regenerate (e.g. a new Python minor, or a version bump):
#   pip download --no-deps --only-binary=:all: libcst==<version> -d /tmp/libcst-wheels \
#     --platform macosx_11_0_arm64 --platform manylinux_2_28_x86_64 \
#     --platform manylinux_2_28_aarch64 --python-version <3.XX>
#   sha256sum /tmp/libcst-wheels/*.whl
# then rewrite this file and bump `version_pin` in scan_pack.json in the SAME change.
